LC-time 1.4.2

1. 解压本 ZIP；不要在压缩包里直接加载。
2. 打开 chrome://extensions/，开启开发者模式。
3. 首次安装：选择“加载已解压的扩展程序”，选中包含 manifest.json 的解压文件夹。
4. 从 1.4.1 或更早版本升级：先在两个 Chrome 用户配置中分别移除旧版，再加载本版；重新开启一次 IP 时区或选择时区。此次固定了扩展 ID，旧 ID 保存的设置不会自动迁移。不要只覆盖旧文件后刷新。
5. 两个配置的新版 ID 都应为 oljjkibnelfpnchehckndlpbflhfooce。设置仍按配置独立保存。所有打开的配置中都应停用同名的旧 ID 副本，否则旧实例仍可能触发断开。
6. 本版未新增权限，要求 Chrome / Chromium 125 或更新版本。
7. 固定 LC-time 到工具栏。选择时区或打开“使用当前 IP 时区”开关，设置会保存；时区、网页语言和默认字体联动。
8. 更新后在目标网页打开扩展，点击“刷新当前网页”。显示“部分应用”或“未应用”时查看下方原因，可点击“恢复并刷新网页”重试。
9. 浏览器调试提示的“取消”和“×”都会断开连接，扩展不能仅隐藏该提示。主动刷新网页或在扩展内恢复可重新启用。
10. 如仍然未应用，点击弹窗底部“诊断”，将复制的内容用于排查。复制不可用时会显示可手动复制的文本。显示“连接已断开”不代表判定你点过取消。
11. 恢复浏览器默认设置后请刷新网页，清除旧页面缓存的语言信息。

工具栏图标上行为小时，下行为分钟。弹窗额外显示秒数、日期和 UTC 偏移。
字体从当前电脑已安装字体中选择，只影响网页默认字体，网站明确指定的字体优先。

本扩展不会改变真实公网 IP、系统语言、操作系统或硬件参数，不保证完全不可识别。
首次网页导航、首次创建共享 Worker 等仍可能早于模拟设置应用；已缓存的首访检测值不会被追溯改写。
详见 README.md 与 TESTING.md。
