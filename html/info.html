LC-time

让浏览器时间，与你选择的时区一致。

开始使用

  1. 在浏览器扩展菜单中，将 LC-time 固定到工具栏。
  2. 打开弹窗，选择一个时区，或开启“使用当前 IP 时区”开关。
  3. 设置会自动保存并应用，弹窗会显示当前网页的应用结果。时钟旁的“已应用”表示当前核验通过；“待核验”表示仍在检查，“部分应用”表示已发现的内嵌或后台环境存在失败。显示“未应用”时，点击“恢复并刷新网页”；若仍失败，点击底部“诊断”复制连接信息。

多个用户配置与升级

从 1.4.1 或更早版本升级时，先在各个 Chrome 用户配置中移除旧版，再加载 1.4.2 并开启 IP 时区或选择时区。新版固定扩展 ID，避免不同解压目录下的同名副本造成连接冲突；设置仍按用户配置独立保存。

读懂你的电子钟

弹窗显示所选时区的时间、日期和 UTC 偏移，秒数实时更新。工具栏的小电子钟上行为小时，下行为分钟，使用 24 小时制并定期刷新。悬停可查看时区与时间。

语言与字体联动

网页语言、请求语言与日期格式会随时区或 IP 国家/地区切换。默认字体从电脑已安装的字体中选择，可单独关闭联动；影响当前用户配置的默认字体，网站指定字体仍优先。多语言地区使用预设，可在手动配置中调整。此功能不修改 Chrome 菜单语言，也不会自动翻译网页。

页面与后台环境

设置同步到可连接的内嵌框架及后台 Worker。首次打开网页、首次创建共享 Worker 时仍可能存在应用窗口；切换设置后建议点击“刷新当前网页”。已缓存的检测结果不会被追溯修改。本功能不改变真实 IP、操作系统或硬件信息，也不保证网站无法识别模拟环境。

恢复默认设置

选择“使用浏览器默认时区”，即可清除自定义的时区、语言、默认字体和位置设置。恢复后请刷新网页以清除页面缓存的语言信息。更多选项在“语言、字体与位置”中。

关于 IP 与浏览器提示

使用 IP 时区会查询当前网络出口的位置，不会改变 IP 地址。扩展沿用浏览器调试接口应用设置，浏览器可能显示正在调试的提示。点击提示的“取消”或右侧“×”都会断开连接；需要恢复时，可主动刷新网页，或点击扩展中的“恢复并刷新网页”。部分浏览器内部页面不支持修改时区。
